A fully functional stopwatch built using HTML, CSS, and JavaScript with a modern blue gradient UI.

Features
✅ Start / Stop / Reset
✅ Lap functionality
✅ Responsive and clean design
✅ Smooth gradient effects

Usage
Start: Begin timing
Stop: Pause the stopwatch
Lap: Record current time
Reset: Clear all data

Technologies Used
HTML
CSS (Gradients, Glassmorphism)
JavaScript (Timing & DOM manipulation)
